내 PC에서 업데이트 (권장)
  1. 처음 한 번만 Google Cloud CLI 로그인을 확인합니다.
     PowerShell에서: gcloud auth list
     로그인된 계정이 없거나 다른 계정이면: gcloud auth login
     발쫀봇 GCP 프로젝트에 접근 가능한 Google 계정으로 로그인합니다.
  2. 변경 코드를 GitHub main에 커밋·푸시합니다.
  3. 이 폴더의 Update-Bot.cmd를 더블클릭하고 대상 서버를 확인한 뒤 Y를 입력합니다.
     최초 SSH 접속 시 키 생성·서버 확인 안내가 나타날 수 있습니다.
     이 도구는 사용자 폴더의 .ssh\valjjonjam_deploy 전용 키를 사용합니다.
     기존 google_compute_engine 키는 그대로 두며, 전용 키도 덮어쓰지 않습니다.
     전용 키가 불완전하다는 오류가 나면 파일을 지우거나 덮어쓰지 말고 확인하세요.
  4. active와 업데이트 완료 문구를 확인하고, Discord에서도 봇 동작을 확인합니다.

  - 대상: project-df59d642-8234-4a5d-859 / us-west1-a / valjjonjam-bot
  - 서버 계정·코드 위치: kmg05027 / ~/bot
  - 봇은 GCP에서 계속 실행됩니다. 업데이트 후 내 PC를 꺼도 됩니다.
  - 서버 VM은 실행 중이어야 합니다. 이 도구는 VM을 켜거나 끄지 않습니다.
  - 서버가 main 브랜치가 아니거나 추적 파일에 수정사항이 있으면 중단합니다.
  - 코드 받기에 실패하면 재시작하지 않습니다. 강제 덮어쓰기나 자동 병합은 하지 않습니다.
  - 봇 코드 업데이트용입니다. 패키지 설치나 환경변수 변경은 자동 수행하지 않습니다.
  - 실행 중 오류가 나면 창의 오류 내용을 확인합니다. 로그인·접속 권한·서버 경로가
    바뀌었을 수 있습니다. 업데이트 도중 실패한 경우 일부 단계는 적용됐을 수 있습니다.
  - Update-Bot.cmd와 Update-Bot.ps1은 같은 폴더에 두세요.
    바탕화면에서 실행하려면 Update-Bot.cmd의 바로 가기를 만드세요.

서버 SSH 다시 여는 법 (수동 업데이트·문제 확인용)
  1. https://console.cloud.google.com/compute/instances 접속
  2. valjjonjam-bot 줄의 SSH 버튼 클릭 → 검은 터미널 창 열림

서버에서 — 새 코드 받고 봇 재시작

  SSH 창에 아래 한 줄 붙여넣고 엔터:
  cd ~/bot && git pull && sudo systemctl restart valjjonjam
  이게:
  - git pull → GitHub에서 방금 올린 새 코드 받기
  - systemctl restart valjjonjam → 봇을 새 코드로 재시작

 잘 됐는지 확인

  sudo systemctl status valjjonjam
  → active (running) 뜨면 성공. 디스코드에서 봇 온라인인지도 한번 보세요.
